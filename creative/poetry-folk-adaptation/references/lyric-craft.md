# 歌词创作技法手册（lyric-craft）

填词阶段的深度参考。核心信念：**改编不是翻译，是让古人在你的歌里重新活一次。**

---

## 一、五家笔法精要（可单独研习，可融合使用）

### 1. 黄霑魂 · 豪气入词
- 短句蓄力，长句喷发；敢用大词（天地、江湖、山河、生死），但必须落在具体小物上才不空洞。
- 叠词与复沓制造声浪："摇晃 摇晃 摇碎了一池月亮"。
- 侠气句式："既然这人间容不下我……不如……"（让步+超脱）。
- 适用母题：江湖退隐、失意自渡。

### 2. 林夕魂 · 物象寓情
- 找一件"信物"贯穿全曲：一钵泪、一枝愁、一枚断簪、半碗孟婆汤。物的变迁即情的变迁。
- 矛盾修辞写纠结："我修我的禅，却在念你的名字""我走我的路，却在读你的影子"。
- 结尾给"放下"或"放不下"一个佛理式注脚："愿你我，下个轮回，不谈佛，只谈情"。
- 适用母题：爱别离、怀人、禅意。

### 3. 罗大佑魂 · 时代叙事
- 把个人放进坐标系：长安的榜单、烽火狼烟、满城脂粉——大背景一笔带过，落在"榜单的裂缝里走脱"这样具体的人身上。
- 批判用反讽和对照："这江水总是比功名利禄还要清澈""满船孤寂竟沉过满城脂粉"。
- 终句要有史笔的重量："往心安处"。
- 适用母题：时代浮沉、失意自渡。

### 4. 李宗盛魂 · 口语白描
- 每首歌至少三句"说人话"："说了怕惹你泪湿眼眶""哪怕无人共我举杯也无妨"。
- 人生感悟句式：先自嘲后通透——"把那遗憾都留下，带走这一船梦里的花"。
- 咬字要能唱：双音节词为主，避免生僻字入副歌。
- 适用：所有母题的白话落地层，尤其尾声。

### 5. 方文山魂 · 意象蒙太奇
- 名词性意象跳接，省略连接词，让画面自己讲故事："长安的雪 还没落进 谁的笔墨 / 我已在 榜单的裂缝里 走脱"。
- 通感与移就："乌鸦把最后一抹夕阳啄落""东风是把生了锈的刀""把回忆磨成一枚断掉的簪子"。
- 古典道具现代化出场：手机不出现，但"锦书难托"可以变成"没着落的下半刻"。
- 适用：主歌铺陈、画面感段落。

**融合配方（成名曲默认配方）**：方文山铺画面（主歌）→ 林夕埋信物（贯穿）→ 罗大佑定格局（背景）→ 黄霑给气口（副歌爆发）→ 李宗盛收人心（预副歌/尾声）。

## 二、原诗句处理八法（改编核心技艺）

以"醉后不知天在水，满船清梦压星河"（唐温如）为例：

| 技法 | 做法 | 示例 |
|------|------|------|
| 1. 直引 | 原句原样嵌入，作副歌锚点 | "醉后不知天在水 / 唯有满船清梦压星河" |
| 2. 镶嵌 | 原句拆半，中间镶新句 | "满船清梦……压星河……"（尾声回环） |
| 3. 转译 | 意象保留，说法现代化 | "西风吹老洞庭波"→"又是一夜湘君白发多"（扩写神话人物） |
| 4. 反写 | 用现代结论回应古人之问 | "既然这人间留不住我片刻的洒脱 / 今夜我便是那银河里唯一的传说" |
| 5. 续写 | 顺着原句意境往下说 | "曾许下的宏愿 如今都化作 涟漪一朵 / 随那 浪花起落" |
| 6. 独白化 | 让诗中人开口说话 | "先生 借问 这船往哪儿开？/ 往 心安处" |
| 7. 对写 | 原句给男声，新句给女声应答 | 男："月落乌啼霜满天" / 女："你枕着半生苍老的执念" |
| 8. 数点 | 拆解原作意象逐个点名入词 | 《钗头凤》→"错、错、错""莫、莫、莫""瞒、瞒、瞒"作三处和声记忆点 |

**选用原则**：一首歌锚点直引不超过 2 句（多了变诗词串烧）；其余七法混用；终段副歌必须换一种技法处理原句（如第一遍直引、第三遍反写），体现"改编者的成长"。

## 三、段落写作规范

### 主歌（Verse）——叙事承重
- 每段 4–6 行，完成"一个人在某个地方做一件事"。
- 首句必须给画面（天气/光线/声音），中段给动作与道具，尾句埋情绪钩子引出预副歌。
- 两段主歌之间必须有信息增量：V1 起（场景），V2 转（身世/转折），V3（如有）合（解悟）。

### 预副歌（Pre-Chorus）——情绪爬坡
- 2–4 行，句式渐短，为副歌蓄力。
- 经典句式："我不怕……只怕……"（对比递进）。

### 副歌（Chorus）——记忆点制造
- 4–8 行，**原诗锚句必须在此**。
- 设计三重记忆点之一：叠词（摇晃摇晃）、数词递进（错/莫/瞒）、呼语开头（"听""叹""看"领起）。
- C1→C2 尾句微调，C3 整段改写升华并标注升调。

### 桥段（Bridge）——跳脱与哲思
- 2–6 行，节奏、视角或人称必须变化（如全曲唯一一段直白告白/设问/对话）。
- 好桥段是"全歌的答案"："往心安处""不谈佛只谈情"。

### 尾声（Outro）——落点
- 三选一：核心句回环渐弱 / 环境音+一句白话收梢 / 男女声各一句短答+合声。
- 尾声是听众带走的那句话，必须是全歌最轻也最重的一笔。

## 四、韵脚方案

- **副歌**：一韵到底，选开口呼（ang/an/ao/ong/iang）显辽阔，选齐齿呼（i/ie/iu）显幽咽。
- **主歌**：可换韵、可用邻韵，两句一韵即可，避免为韵害意。
- **对唱**：男声段与女声段可各守一韵，合唱段两韵交汇（呼应"两个世界的人"）。
- 自查法：只读每行末字，能感到"回环"即合格；读到卡壳处必改。

---

## 五、对唱与角色化方案

- **人设先行**：动笔前写两人一句话小传（"落第书生：把功名输给了一江秋水""江水化身：守渔火千年，只等一个肯留下的人"）。
- **声部语法**：（男）（女）独述各自心事 → 过渡句男女互答 →（合）副歌求同存异 → Bridge 交叠争辩/和解 → 尾声各自一句+合声落点。
- **信息差**：两人知道的不能一样（僧知戒律不知情、俗知情不知禅），信息差就是戏剧张力。
- 独唱作品的角色化：给自己造一个"对手"（一壶酒、一座城、一盏灯），全程与它对话。

## 六、成名曲自检十问

1. 副歌单听一遍，能哼出记忆点吗？
2. 原诗最出名的那句，听众能在副歌里等到吗？
3. 删掉歌名，歌词里有没有一句"只有这首歌才有"的句子？
4. 五个词人的魂，至少化用了几家？
5. 有没有一个道具从头贯到尾？
6. 终段副歌与第一遍比，人物成长了吗？
7. 尾声那句话，值得听众设成签名吗？
8. 每一段都有画面吗（闭眼能看见）？
9. 口语句与古语句的比例约 7:3 吗（白话是肉，古意是骨）？
10. 三分钟以上的时长，是靠信息量撑的还是靠重复注水的？
