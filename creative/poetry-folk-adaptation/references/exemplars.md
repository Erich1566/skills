# 典范作品拆解（exemplars）

五首源自"AI音乐知识库"的标杆作品。用途：创作卡壳时对照研读，校准"成名曲水准"。每首附全文与技法拆解。

## 范本一 ·《不思量》—— 独唱 · 悼亡怀人 · 苏轼《江城子》

**曲风**：前奏清脆木吉他扫弦，间奏加入幽咽笛声或箫。
**技法要点**：苏轼全词逐句化用——原句直接充当每段骨架，白话新句填肉。

> [Verse 1]
> 城郊的风 吹皱了一池旧事 / 纸上的墨 还没干透就成了诗
> 我提笔 试图在荒芜里寻一丝 / 你走后 那些没说出口的固执
> 日子很长 长过这窄窄的巷子 / 酒杯很浅 却装不下半生痴
> 我把回忆 磨成了一枚断掉的簪子 / 在每一个 醒不来的夜里 试了又试
>
> [Pre-Chorus]
> 谁在唱着 那首没名字的残曲 / 把光阴 剪成了一地零碎的期许
> 我也曾 鲜衣怒马 走过万里云烟绿 / 如今却 只剩这一身 荒唐的空虚
>
> [Chorus]
> 十年生死两茫茫。不思量，自难忘。
> 这红尘太跌宕 谁又能躲得过 岁月这把枪
> 纵使相逢应不识，尘满面，鬓如霜。
> 你依旧是 惊鸿一瞥 那个旧时模样
>
> [Verse 2]
> 昨日黄花 还在那土里倔强 / 窗外的蝉 替我诉说那些迷惘
> 我路过 每一个 你曾提过的远方 / 却发现 所有的终点 都是你的脊梁
> 你说过 哪怕山高路远也要 守望 / 我却在 泥泞的途中 弄丢了行囊
> 你是旧梦里的词 我是这现世里的荒 / 我们在 不同的时空 共享月光
>
> [Bridge]
> 夜来幽梦忽还乡，小窗，正梳妆。
> 烛火晃了晃 晃出你侧脸的微光 / 我伸出手 却只触碰到 冰冷的晚凉
> 相顾无言，惟有泪千行。
>
> [Chorus 2]
> 十年生死两茫茫。不思量，自难忘。
> 这红尘太跌宕 谁又能躲得过 岁月这把枪
> 纵使相逢应不识，尘满面，鬓如霜。
> 我早已不是 鲜衣怒马 那个意气儿郎
>
> [Outro]
> 料得年年肠断处，明月夜，短松冈。
> 我守着那一地 荒凉。再干一碗 剩下的 孟婆汤。
> （吉他声渐弱，余音戛然而止）

**拆解**：①副歌锚点=词牌原句+现代句"岁月这把枪"对撞；②道具"断簪"贯穿主歌；③Bridge 用"还乡梦境"做全歌唯一柔软处，紧接"泪千行"原句收力；④尾句"再干一碗剩下的孟婆汤"是李宗盛式白话落点；⑤C2 尾句从"你依旧是"改为"我早已不是"，人称一换、十年沧桑尽出。

## 范本二 ·《沈园折》—— 独唱 · 爱别离 · 陆游《钗头凤》

**曲风**：新民谣（参考谢春花/花粥），木吉他/竹笛/雨声采样；Intro 吉他扫弦+远处模糊叫卖。
**技法要点**：《钗头凤》三叠字"错错错/莫莫莫/瞒瞒瞒"拆成三处和声记忆点，全词嵌入副歌。

> (Intro)（吉他清脆的扫弦声，伴随远处几声模糊的叫卖）
>
> (Verse 1)
> 我偷了时光一壶 隔年的黄縢酒 / 撞进这满园春色 撞见宫墙柳
> 你看那 灰扑扑的瓦 像不像老去的离愁 / 你提着裙摆 走过我梦里的 每一个关口
>
> (Verse 2)
> 东风是把生了锈的刀 劈不开回头路 / 你说人情太薄 像一场 没打伞的雾
> 那一年 桃花落得 没名没姓 没个归处 / 谁把 满怀心事 都喂了 沈园的泥土
>
> (Pre-Chorus)
> 我不怕 命运它 颠沛流离 没个定数 / 只怕 你的眉间 锁着我 跨不过的 荒芜
>
> (Chorus)
> 红酥手，黄縢酒，满城春色宫墙柳 / 你颤着指尖 递来半生 换不回的 缠绵路
> 东风恶，欢情薄。一怀愁绪，几年离索。/ 谁在斑驳的墙头 写一笔 错、错、错。
>
> (Interlude)（笛子悠扬转低沉，仿佛穿越时空的叹息）
>
> (Verse 3)
> 山盟虽在 却被风 吹成了一纸 荒唐课 / 锦书难托 像不像 我们 没着落的 下半刻
> 你在 谁的檐下 躲雨 躲过 命运的 刀客 / 我在这 墙根底下 成了 最潦倒的 笔墨
>
> (Bridge)
> 别问了 别问了 那些泪 早就干成了 壳 / 你也 瞒着 我也 瞒着 咽下这 苦涩
> 春如旧，人空瘦，泪痕红浥鲛绡透 / 桃花落，闲池阁 / 山盟虽在，锦书难托
>
> (Chorus - Variation)
> 红酥手，黄縢酒，满城春色宫墙柳 / 这一杯 喝下去 敬你 依旧清澈的 眼眸
> 莫、莫、莫 / 最后的 那个字 是我 唯一 敢给你的 自由
>
> (Outro)
> 怕人寻问，咽泪装欢 / 瞒，瞒，瞒
> 这园子 关得住 春 / 关不住 那声 经年不散的 喟叹……
> （音乐随雨声收尾）

**拆解**：①"错错错→莫莫莫→瞒瞒瞒"分布副歌、C变奏、尾声，形成三幕递进；②"偷了时光一壶黄縢酒""东风是生锈的刀"是方文山式陌生化范本；③量词范本："一壶隔年的酒""一纸荒唐课""一墙根潦倒笔墨"；④尾声用"关得住春/关不住喟叹"对仗收梢。

## 范本三 ·《梦压星河》—— 独唱 · 失意自渡 · 唐温如《题龙阳县青草湖》

**曲风**：新民谣/古风/流行，BPM 88，舒缓摇摆；前奏纯木吉他渐入笛声，间奏加手鼓与古筝对答，终段升调。

> (Verse 1)
> 我路过人间这一处 渡口叫做荒唐 / 卸下了二两功名 换一身粗布衣裳
> 也没敢惊动 住在传说里的那位 湘君神朗 / 只敢趁着月色微凉 偷偷借宿在他的 鱼米之乡
>
> (Verse 2)
> 那时候少年心事 总比那 天地还狂 / 以为剑锋所指的地方 就是心之所向
> 直到这流年辗转 磨平了 眉间的 桀骜锋芒 / 才懂最好的归宿 不过是 这一汪 琉璃水光
>
> (Pre-Chorus)
> 此去山河岁月长 / 哪怕无人共我 举杯也无妨
> 你看那水面 倒映着 谁的前世今生 浩浩汤汤 / 摇晃 摇晃 摇碎了 一池月亮
>
> (Chorus 1)
> 听 / 西风吹老洞庭波 / 又是一夜湘君白发多 / 曾许下的宏愿 如今都化作 涟漪一朵 / 随那 浪花起落
> 叹 / 醉后不知天在水 / 唯有满船清梦压星河 / 既然这人间 容不下我 太多的 痴心疯魔 / 不如 枕着银河 睡去 且由他 岁月蹉跎
>
> (Interlude)（间奏加入轻快的手鼓与古筝对答）
>
> (Verse 3)
> 不用问来时的路 也别问 我要去何方 / 故事都藏在酒里 说了怕 惹你 泪湿眼眶
> 这里没有 烽火狼烟 / 也没有 谁负了谁的 红妆 / 只有芦苇荡里 藏着几只 惊醒的 睡鸳鸯
>
> (Chorus 2)（同 C1，尾句改：不如 枕着银河 做一个 逍遥的客）
>
> (Bridge)
> 如果醒来 又是浮生一刹那 / 谁还记得 昨夜星辰 昨夜的风沙
> 把那 遗憾都留下 / 带走这一船 梦里的花
>
> (Chorus 3 - 升调，情感更浓烈)
> 看 / 西风吹老洞庭波 / 又是一夜湘君白发多 / 这世间的悲欢 原来都不过 涟漪一朵 / 随那 浪花起落
> 笑 / 醉后不知天在水 / 任他满船清梦压星河 / 既然这人间 留不住我 片刻的 洒脱 / 今夜 我便是那 银河里 唯一的 传说
>
> (Outro)
> 满船清梦…… 压星河……
> （渐弱，只剩一声水滴落下的空灵回响）

**拆解**：①三遍副歌用呼语"听/叹→看/笑"标记情绪升级；②"渡口叫做荒唐""二两功名"是量词+命名式修辞范本；③C3 关键动词替换："唯有→任他""容不下→留不住"，从被动承受翻成主动超脱——这就是"终段升华"的标准动作；④尾声单句回环+水滴音效。

## 范本四 ·《还卿录》—— 男女对唱 · 禅意爱别离 · 苏曼殊《本事诗》

**曲风**：新民谣，木吉他、竹笛、木鱼声、轻微雨声采样；男声清冷克制，女声空灵如烟。

> (前奏：轻微的木鱼声，转入木吉他扫弦，淅沥的雨声)
>
> (男) 打马走过 那个荒芜的渡口 / 僧衣被 晚来的风 吹得有些旧 / 我手里 攥着一卷 没读完的春秋 / 却不知 该往 哪座山头 走
> (女) 你敲过 哪扇 没上锁的陈旧 / 把那口 枯井的月 惊扰了半秋 / 我折下 这一枝 谁都没见过的愁 / 在长亭 站成了 你的回头
> (男) 乌舍凌波肌似雪 你撑着伞 隔着 漫山遍野的雪
> (女) 亲持红叶索题诗 我借着墨 涂抹 那个未完的约
>
> (合 - 副歌)
> 你说这 众生皆苦 我是那一味 / 你说这 菩提无树 心上有尘灰 / 我把这 往事煮沸 换一碗 没名字的泪
> (男) 还卿一钵无情泪 / (女) 恨不相逢未剃时
>
> (男) 戒疤是 这一生 绕不开的城 / 木鱼声 碎在 那个 不归的黄昏
> (女) 红线是 这一世 认不出的门 / 你转身 成了 那个 最深情的僧
> (男) 我修我的禅 却在 念你的名字 / (女) 我走我的路 却在 读你的影子
> (男) 看那 凡尘中的 烟火 烧得正热烈 / (女) 看这 佛门里的 灯火 冷得太直接
>
> (Bridge) (男) 那红叶 还没 枯萎 / (女) 那题目 还没 写对 / (合) 错过了 这一场 相逢 竟要用 余生 来 追随
>
> (尾声) (男) 还卿一钵无情泪…… (女) 恨不相逢未剃时……
> (男) 檀香已尽。(女) 红叶已冷。(合) 愿你我，下个轮回，不谈佛，只谈情。
> (后奏：吉他声渐远，最后一声清脆的铃铎声)

**拆解**：①信息差写法——僧知禅不知情、俗知情难近禅，每段对唱都在错位；②道具双线："红叶/檀香"与"戒疤/木鱼"分别代表俗与佛；③原诗"还卿一钵无情泪，恨不相逢未剃时"拆成男女各一句作副歌终点，对唱改编的黄金范本；④尾声四短句"檀香已尽/红叶已冷"蒙太奇收幕，合声落点直白且狠。

## 范本五 ·《寒山记/姑苏未眠人》—— 男女对唱 · 失意自渡 · 张继《枫桥夜泊》

**曲风**：唯美民谣/古风新编，轻快而略带忧伤；木吉他扫弦开场，间奏加钟声笛音铃铛，尾声只剩一把木吉他。

> (前奏：孤独的竹笛+轻微水声+木桨划水声)
> (男) 长安的雪 还没落进 谁的笔墨 / 我已在 榜单的裂缝里 走脱 / 换一身 浆洗发白的 寒酸布褶 / 拎一壶 苦酒去 渡这一场 离合
> (女) 你听 乌鸦把 最后一抹 夕阳啄落 / 这江水 总是比 功名利禄 还要清澈 / 你坐着 小舟 穿过 岁月的 沟壑 / 我守着 渔火 等你 这一夜 的 萧瑟
> (男) 月落乌啼霜满天 / 我 摊开 手心里的 茧 / 长安 欠我的 那个 状元 / 抵不过 这一刻 寒气的 蔓延
> (女) 江枫渔火对愁眠 / 你 枕着 半生 苍老的 执念 / 有些 梦啊 注定 要 碎在 枕边 / 才算 没辜负 这一场 遇见
> (间奏：吉他扫弦由缓转急+轻快铃铛声，类似《盗将行》的灵动感)
> (男) 笔尖 错落了 功名 却拓下了 余生 / 你看这 满船 孤寂 竟沉过 满城 脂粉
> (女) 谁在 敲门 谁在 寻人 / 谁又在 寒山寺 借一抹 晚钟 沉沦
> (合) 姑苏城外寒山寺 夜半钟声到客船
> (男) 那钟声 敲在 谁的心头 / 震了三遍 敲碎了 贪婪 / 敲醒了 那些 卑微的 脸
> (女) 那钟声 落在 你的 船头 / 忽隐 忽现 渡你的 狼狈 渡你的 遗憾 / 回到 故园
> (Bridge：男女声部交叠，节奏加快，民谣随性感)
> (男) 我不求 烈火烹油 鲜花着锦 / 我只求 这一瓢 江水 涤净 尘襟
> (女) 你尽管 借这一夜 酩酊大醉 / 哪怕 到了 明朝 依旧是 满身 烟云
> (副歌：宏大且深情)
> (合) 月落乌啼霜满天，江枫渔火对愁眠 / 姑苏城外寒山寺，夜半钟声到客船
> (男) 世界 敲醒了 我 / (女) 也 敲碎了 梦
> (尾声：音乐渐弱，只剩一把木吉他)
> (男) 先生 借问 这船 往哪儿开？ / (女) 往 心安处。 / (合) 往……心安处。

**拆解**：①原诗四句拆成"男两句+女两句"与"终副歌全诗合唱"两级火箭；②人设一句话小传先行——落第书生×江水化身，信息差=功名 vs 心安；③"乌鸦啄落夕阳""榜单的裂缝里走脱"方文山式意象范本；④尾声设问句"往哪儿开？往心安处"是全歌落点，罗大佑式史笔+李宗盛式白话合体。
