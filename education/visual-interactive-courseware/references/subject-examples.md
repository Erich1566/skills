# 学科拆解模式库

按学科整理的"哪些知识点适合做成可视化交互课件"及拆解要点。生成 SVG 前先查此表，找到同类模式直接套用交互骨架。

## 通用拆解口诀

1. 先全景，后局部（总览 → 分支 → 细节 → 回到全景连贯）
2. 先静态，后动态（结构认清楚，再看过程动起来）
3. 先演示，后归纳（学生观察现象 → 数据面板 → 提炼规律）
4. 结尾必有小测（2–3 道选择题，即时反馈）
