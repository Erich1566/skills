# 两步工作流详细执行规范

## 第一步：知识整合

### 1.1 检索原则

- **来源优先级**：教材出版社官网（人教、北师大等）> 教育部/省级课程资源平台 > 学科专业机构（博物馆、科研机构、标准化组织）> 权威百科（仅作交叉验证，不作唯一来源）。
- 检索关键词组合：`<知识点> 教材 人教版 <年级>`、`<知识点> 教学 课程标准`、`<专业术语> 权威解释`。
- 每条关键知识（数值、名称、过程结论）必须在 `01-知识整合.md` 中标注来源 URL。
- 检索不到权威来源的内容，标记为 `[待验证]`，不得静默编造。

### 1.3 SVG 参考图生成

- 每个 SVG 一个独立文件，自包含（内联全部样式，无外部引用），可直接在浏览器打开验证。
- 文件名语义化：`肺循环.svg`、`体循环.svg`、`四羊方尊-结构分层.svg`。
- 绘制顺序：先画结构骨架（几何准确），再加标注（引线+文字），最后上色。
- 参考图是第二步课件的"素材库"，课件中可以直接复用其 SVG 代码。

## 第二步：课件生成

### 2.1 模块拆解表

| 知识类型 | 典型例子 | 建议模块拆解（4–8 幕） | 核心交互 |
|---------|---------|----------------------|---------|
| 循环/流程 | 血液循环、水循环、氮循环 | ①总览全景 ②分支A（肺循环）③分支B（体循环）④交汇处细节 ⑤连贯完整动画 ⑥随堂小测 | 路径流动动画、分支切换开关、点击节点高亮 |
| 结构/器物 | 四羊方尊、细胞、发动机 | ①整体外观 ②逐层剖切 ③关键部件特写 ④工艺/功能演示 ⑤知识卡汇总 | 滑块剖切、部件点选、爆炸图展开 |
| 地理现象 | 晨昏线、二分二至、月相 | ①现象定义 ②参数演示（拖日期/纬度） ③极端情况（极昼极夜）④规律总结 | 日期滑块驱动太阳直射点、纬线圈动态着色 |
| 几何/物理 | 凸透镜成像、单摆、电路 | ①装置认知 ②拖动自变量 ③临界点捕捉 ④规律归纳 | 拖拽物/滑块实时联动、数据面板实时读数 |
| 历史/叙事 | 商鞅变法、丝绸之路 | ①时间轴总览 ②逐段展开 ③关键事件特写 ④影响与评价 | 时间轴拖动、地图路径动画 |

### 2.2 SVG 类型决策树

```
知识核心是"过程/流动"？
├─ 是 → 路径动画型 SVG（渐变描边 + dash 流动 + 辉光滤镜 + 步骤序列器聚光）
│        需要分支切换？→ 顶栏模式 Tab 组做图层显隐（如肺循环/体循环分看）
└─ 否 → 知识核心是"空间结构"？
         ├─ 是 → 分层/剖切型 SVG（爆炸图排布"标本卡"，点选部件聚焦+大纲联动）
         └─ 否 → 知识核心是"参数依赖"？
                  ├─ 是 → 滑块驱动型 SVG（input range → JS 重算坐标 + 实时读数）
                  └─ 否 → 时间轴/叙事型 SVG（横向时间轴 + 段落展开）
```

微观结构（肺泡、细胞、分子）必须做"放大场景"：主体 + 缠绕毛细血管 + animateMotion 粒子（红细胞单行、O₂/CO₂ 迁移）。有机形体（心脏、器官）用多段 C 曲线拼真实解剖轮廓，叠半透明弧线做高光沟回，拒绝卡通图形。

### 2.3 课件填充流程

1. **以示例课件为品质基准**：`D:\vibe coding\课件-血液循环示例\课件.html`（专业级样板：应用级外壳 + 深空主题 + 辉光质感 + 步骤序列器）。新课件以此为参照，达不到该水准不算完成。
2. 复制 `assets/template.html` 到项目文件夹并重命名为 `课件.html`（模板含完整外壳骨架；专业细节参照示例课件实现）。
3. 按模块顺序填充：每幕 = 一个 `<section class="scene">`，含叠加字幕标题 + SVG 主视觉 + 浮动任务卡。
4. **每个 `<svg>` 自带 `<defs>`，渐变/滤镜 ID 加幕序号后缀唯一化**（`gArt-2`、`fGlow-3`），引用只指向本 SVG 内的 ID。
   ⚠️ Chromium/Edge 下跨 SVG 引用 `url(#id)`，若目标位于 `display:none` 的 SVG 内会解析失败导致路径消失；重复 ID 同样只认第一个。此坑已实测踩过，禁止再踩。
5. 过程类知识最后一幕配步骤序列器：chip 步骤卡自动步进（2.6s×速度）+ 点击跳步 + SVG 路径 `data-s` 联动聚光（当前步加粗+辉光，其余 opacity .16）。
6. 进幕运镜：`flyCamera(svg, [0,0,1200,760], [x,y,w,h], 1400)` 对 viewBox 缓动插值实现镜头推近。
7. 全局控件（左导航/顶栏模式切换/右侧大纲树/底部控制条）使用模板自带结构。
8. 填充完成后自检（详见 design-guide.md 验收清单）：
   - 三种视口（1600×900/1366×768/1024×768）浏览器截图逐幕检查
   - 每个渐变引用的路径在其他幕激活时依然渲染
   - 步骤序列器自动步进 + 点击跳步正常
   - 播放暂停对 dash/beat/序列器同时生效
   - 控制台 0 报错
