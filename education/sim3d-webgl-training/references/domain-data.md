# 领域数据建模规范（Domain Data Contract）

> **本文件是"惊艳度"之源**：用户感知的精致与完善，90% 来自本文件规定的数据密度，而非渲染技术。
> 写代码前必须先填完 SIM_CONFIG 数据，数据不达标不许进第 2 步。

## §0 为什么数据驱动

高分结构（对标 irb_6700）的核心：**代码与内容彻底分离**。全部领域数据集中在一个声明式对象 `SIM_CONFIG` 中，渲染器/教学机/仪器全部由数据驱动：

```
SIM_CONFIG = { title, badge, cameraPresets[], jointsDefault, limits[], components[], sopSteps[], faults[], workConds[] }
     ↓                    ↓                      ↓
  renderCustomScene   executeCurrentSopStep   updateDmmDisplay
  （遍历 components   （校验 reqPpe/reqPowerOff （读 comp.testPoints
    画几何+高亮）      +score 评分）            随故障态切换值）
```

好处：① 内容密度可以做得极高而不碰渲染代码；② 改设备型号只改数据；③ audit 可静态检测内容密度。

```js
{
  id: "comp_j1",                 // 唯一 id
  code: "J1-BASE",               // 工程编号（显示在 HUD 徽章）
  shortName: "一轴底座与RV减速机", // 短名（HUD 用）
  name: "一轴回转底座与RV-450E减速机", // 全称（右栏标题）
  category: "传动与减速机",        // 分类（左栏分组/筛选）
  color: [0.18, 0.54, 0.86],     // 主题色（RGB 0-1）
  pos: [0.0, -0.78, 0.0],        // 部件锚点世界坐标（HUD 引线起点）
  explodeVec: [0.0, -0.55, 0.0], // 爆炸拆解方向向量（×explode 系数）
  leaderOffset: [-128, 32],      // HUD 徽章屏幕偏移（手工调避重叠）
  principle: "采用二级摆线针轮RV-450E精密减速机与永磁同步交流伺服电机直联，承受全臂倾覆力矩并实现±170°回转定位。",
  specs: [                       // ≥4 行真实工程规格（WebSearch 来源）
    ["额定输出转矩", "1,350 N·m"],
    ["RV减速机速比", "141 : 1"],
    ["重复定位精度", "±0.020 mm"],
    ["润滑脂牌号", "Molywhite RE00"]
  ],
  // ★ 可测数值体系：正常/故障双值 × 4 种电气量。万用表读它，故障注入改读 Fault 值
  testPoints: { vNorm: 24.0, vFault: 24.0, ohmNorm: 1.85, ohmFault: 1.85,
                mohmNorm: 580, mohmFault: 520, ampNorm: 8.6, ampFault: 19.8 }
}
```

### testPoints 设计规范（8 值电气量体系）

| 量 | 万用表档位 | 典型正常值 | 故障值设计技巧 |
|---|---|---|---|
| vNorm/vFault | DC V 电压 | 24.0（控制回路）/540（母线） | 欠压故障 182.5（明显低于正常 >50V 判异常） |
| ohmNorm/ohmFault | Ω 内阻 | 线圈 38.5 / 电机 2.15 / 断路 ∞ | 抱闸断路 1850（>5Ω 偏差判异常） |
| mohmNorm/mohmFault | MΩ 绝缘(500V) | 500–620 | 绝缘击穿 0.38（<10 判异常） |
| ampNorm/ampFault | A 伺服电流 | 随负载 3–15 | 磨损冲击 19.8（>3A 偏差判异常） |

非电气部件（结构臂体）填 0 或 999，万用表切到该件显示原值即可。
**DMM 判异常规则**：`|fault-norm| > 阈值`（V:1.0 / Ω:5.0 / MΩ:10.0 / A:3.0）→ LCD 红显。

## §2 sopSteps[] 数据契约

```js
{
  id: "sop_1",
  title: "穿戴全套PPE劳保防护并执行主电柜LOTO挂牌上锁",
  desc: "依次穿戴安全帽、绝缘手套与防砸绝缘鞋，并将主控柜断路器 QF1 切换至【断电挂牌 LOTO】状态。",
  actionLabel: "核验PPE与LOTO上锁状态",   // 一键执行按钮文案（考核模式隐藏）
  reqPpe: true,        // 要求全套 PPE（未穿 → 报警 -5 分）
  reqPowerOff: true,   // true=要求 LOTO 断电；false=要求合闸上电
  targetComp: "comp_cabinet",  // 镜头飞跃目标
  techPos: [-1.45, 0.65],      // 技师站位（设备包围盒外侧！）
  score: 15                     // 工步分值
}
```

**SOP 链设计**：6 步 ≈ 断电作业（PPE+LOTO → 绝缘遥测 → 抱闸核验 → 换脂排气）→ 上电作业（合闸 → 零点标定 → TCP 寻位复测），体现真实"先断后通"工艺逻辑。

## §3 faults[] 数据契约（故障+盲考二合一）

```js
{
  id: "fault_brake",
  name: "故障一：二轴(J2)伺服电磁抱闸线圈断路/卡滞故障",
  code: "ERR-2041",
  symptom: "示教器报 J2 轴过流与抱闸未释放告警，二轴大臂无法俯仰动作，伺服相电流飙升至 26.5A。",
  targetComp: "comp_j2",
  hint: "将红表笔接【J2-DRIVE 二轴肩部驱动】，切换万用表至【Ω (内阻)】档检测抱闸线圈阻值（正常 38.5 Ω，故障断路 1850 Ω）。",
  quizQuestion: "实测二轴(J2) DC 24V 电磁抱闸供电端电压为 23.8V 正常，但抱闸线圈内阻高达 1850 Ω（标准 38.5 Ω）且二轴卡死，正确的排故规程是？",
  options: [ "A. 直接拆下二轴伺服电机，无需固定大臂",
             "B. 使用吊装带或支撑工装托住二轴主大臂，执行LOTO断电挂牌后更换J2抱闸组件并复测内阻 38.5 Ω",
             "C. 在示教器参数中屏蔽J2转矩限制报警并强行点动" ],
  answerIdx: 1
}
```

**设计铁律**：hint 必须写明"表笔接哪个部件 + 切哪个档位 + 正常/故障数值"——形成"症状→测量→定位→处置"完整闭环，学生不猜，靠仪表数据破案。

## §5 工况库（workConds）——每种设备 3–4 种

| 设备类型 | 工况 | 关节/参数驱动函数（示例） |
|---|---|---|
| 六轴机械臂 | 圆弧焊接 | J1=sin(t)·24°, J5=-48°+sin(t)·10°, J6 连续旋转 |
| | 高速码垛 | J1=s·52°, J2=-28°+\|cos\|·26°, 夹爪随 cos 符号开合 |
| | 零点标定 | 六轴指数收敛 0°（`j += (0-j)*0.08`） |
| | 过载 STO | 高频振动摆幅 ±1.5°（t·22Hz） |
| 运载器/车辆 | 巡航/加速/制动 | 速度-时间曲线 + 挡位状态机 |
| 动力机械 | 怠速/额定/超载 | 转速-负载曲线 + 排温变色 |
